定期存款簿 PWA — 安裝與同步說明
==================================

資料夾內容
---------
index.html            App 本體（全部功能都在這個檔案）
manifest.webmanifest  安裝設定（全螢幕、名稱、圖示）
sw.js                 離線快取（斷網也能開、能記錄）
icons/                鈔票圖示（iPhone、Android 各種尺寸，已做好）
apps-script/Code.gs   Google Drive 同步後端


第一步：把 App 放上網（需要 https）
---------------------------------
iPhone 和 Android 要「安裝成 App」及離線使用，網頁必須放在 https 網址上，
不能直接打開檔案。最簡單的免費做法（二選一）：

 A. Netlify Drop：用瀏覽器打開 app.netlify.com/drop，
    把整個「定期存款簿_PWA」資料夾拖進去，馬上得到一個 https 網址。
 B. GitHub Pages：建立一個 repository，把這個資料夾的內容上傳，
    在 Settings → Pages 開啟，得到 https 網址。

注意：網址不要隨便公開。App 的資料只存在你自己手機裡，
但知道網址的人可以打開一個空白的 App。


第二步：安裝到手機桌面
---------------------
iPhone（要用 Safari）：
  打開網址 → 底部「分享」按鈕 → 「加入主畫面」→ 新增。
  桌面會出現鈔票圖示，點開就是全螢幕，沒有瀏覽器列。

Android（Chrome）：
  打開網址 → 右上角選單 → 「安裝應用程式」（或「加到主畫面」）。


第三步：設定 Google Drive 同步（Google Apps Script）
-------------------------------------------------
1. 用你的 Google 帳戶打開 script.google.com → 新增專案。
2. 把專案裡原有的程式碼全部刪除，貼上 apps-script/Code.gs 的全部內容。
3. 把第一行 const TOKEN = '請改成你自己的密碼'; 的密碼改成你自己的
   （長一點、難估，之後要在 App 裡填同一個）。
4. 按右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
     執行身分：我
     誰可以存取：所有人
   按「部署」。
5. 第一次會要求授權：選你的帳戶 →（若顯示「Google 尚未驗證這個應用程式」）
   按「進階」→「前往（不安全）」→ 允許。
   這是你自己寫的程式，只會讀寫 Drive 裡的「定期存款簿」資料夾和檔案。
6. 複製畫面上的「網頁應用程式網址」（結尾是 /exec）。
7. 打開 App → 右上角 ⚙ → 「Google Drive 同步」：
     貼上網址、填入密碼 → 按「測試連線」，看到「連線成功」就完成。

之後 Drive 會自動出現「定期存款簿」資料夾：
  ledger.json         最新資料
  ledger.backup.json  上一次被覆蓋前的版本（自動備份）


日常使用
--------
・上傳：把這部裝置的資料存到 Drive。
・下載：用 Drive 的版本取代這部裝置的資料（會先確認）。
・自動上傳：勾選後，每次修改資料約 3 秒後自動上傳；
  離線時會先記著，恢復網絡後自動補上傳。
・換新手機 / 第二部裝置：安裝 App → 填同樣的網址和密碼 → 按「下載」。

安全保護：
・如果雲端的資料比這部裝置所知的版本新（例如你在另一部裝置改過），
  上傳會先停下來問你，不會悄悄覆蓋。
・每次覆蓋雲端前，舊版本都會自動存成 ledger.backup.json。
・若自動上傳停在「需處理」，到設定按「下載」取回雲端版本，或手動「上傳」並確認覆蓋。

如果修改了 Code.gs：要在 Apps Script 按「部署」→「管理部署作業」→
編輯（鉛筆）→ 版本選「新版本」→ 部署，網址保持不變。


更新 App 內容之後
----------------
重新上傳 index.html 後，請把 sw.js 第 3 行的版本號加 1（例如 fd-ledger-v3 → v4），
手機才會取得新版本。


從舊版（單一 HTML 檔）搬資料
--------------------------
新網址和舊版是不同的「來源」，資料不會自動帶過來。
請在舊版：⚙ →「匯出 JSON」，再到新版：⚙ →「匯入 JSON」→ 選「確定」覆蓋。
搬完之後，按「上傳」就會存到 Drive。


私隱說明
--------
・同步密碼和網址只存在你手機的瀏覽器內，不會放進匯出的 JSON 備份。
・密碼同時寫在你自己的 Apps Script 程式碼裡，請勿與別人分享該專案或網址。
